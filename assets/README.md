# assets/

Tudo que o navegador baixa para renderizar o site.

## css/

| Arquivo | Função |
|---|---|
| `guiwave.css` | Folha única: layout, paleta, componentes e páginas |

## js/

| Arquivo | Função |
|---|---|
| `data.js` | Dados de produção: artista, LP, agenda e casas (`window.GUIWAVE`) |
| `guiwave.js` | Menu, rodapé, cookies, carrossel, countdown, lists, lightbox e form |
