# seo/

Arquivos de descoberta. Precisam existir nas URLs de raiz; aqui é só o armazenamento.

| Arquivo | URL pública | Função |
|---|---|---|
| `robots.txt` | `/robots.txt` | Permissão de crawlers + sitemap |
| `sitemap.xml` | `/sitemap.xml` | Índice das URLs canônicas |
| `manifest.webmanifest` | `/manifest.webmanifest` | Nome, ícone e tema PWA |
